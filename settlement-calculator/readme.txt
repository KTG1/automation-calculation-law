A customizable settlement estimator with a single-column layout, tabbed FAQs, and an admin editor.

== Description ==

Settlement Calculator creates and publishes a page at `/settlement-calculator/` during plugin activation. The page contains a browser-based estimator for economic damages, non-economic damages, comparative fault, attorney fees, case costs, and liens.

The `[settlement_calculator]` shortcode can also be placed on any post or page.

Every visible text segment can be edited at Settings > Settlement Calculator. FAQ tabs, questions, and answers can be added or removed from the same screen.

All calculations run in the visitor's browser. No entered values are stored or transmitted.

This calculator is a general planning tool and does not provide legal advice.

== Installation ==

1. Upload the `settlement-calculator` folder to `/wp-content/plugins/`, or install the ZIP through Plugins > Add New > Upload Plugin.
2. Activate Settlement Calculator.
3. Visit `/settlement-calculator/`.
